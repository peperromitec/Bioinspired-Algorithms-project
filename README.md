# Planta Física · Monthly challenge · MA2015.202

We construct and explain a genetic algorithm for four buildings using March 2025 demands. We keep formulation, manual calculation, code, results and interpretation in one cumulative notebook.

## Start from the common base

1. Extract all five files into the same folder.
2. Read the [challenge guide](challenge_guide_planta_fisica.pdf) to identify criteria, deadlines and evidence.
3. Prepare Python 3.12-3.14 and run `uv sync --locked`.
4. Run `uv run jupyter lab` and open [the notebook](planta_fisica_minimum_solution.ipynb).
5. Restart the kernel and run every cell in order. Compare the manual calculation with the output.
6. Integrate your team's explanation and record changes and role rotation in the same notebook.
7. Keep the outputs and submit the cumulative version with both environment files, as specified in the guide.

Data and code are embedded. The 1410 m³ capacity and building limits are teaching assumptions. We compare the base and one mutation variation to interpret the operators and results. Understanding and evidence using the supplied base can earn 100 under the rubric.
